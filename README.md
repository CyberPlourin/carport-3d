# Carport 3D sur photo — Cyberia

Page web qui place un carport en 3D sur la photo d'un terrain, pour visualiser un projet avant travaux. Conçue au fablab de Cyberia (Plourin).

**Utiliser l'outil :** https://cyberplourin.github.io/carport-3d/

- Chargez la photo du terrain (bouton, glisser-déposer ou Ctrl + V)
- Réglez l'emplacement, l'angle de vue, les dimensions, le toit (plat ou deux pentes), l'habillage, l'appareil photo et le soleil
- Générez l'image du projet, puis copiez-la ou enregistrez-la

Rien n'est envoyé sur Internet : la photo reste dans votre navigateur.
Fonctionne sur ordinateur, dans un navigateur récent (Firefox, Chrome, Edge).
